Thinking / 推論トークンについて

多くのモデルでは thinking（内部推論）も出力トークンと同じ $/1M で課金されます。 画面上の短文だけを入れると、実際の請求は桁違いになることがあります。 下のフォームでは「表示テキスト」と「thinking」を分けて入れられるようにし、 両方を足したトークン数に出力単価を掛けて計算します（API の usage と揃えるなら thinking を 0 にして、出力欄に合計だけ入れても構いません）。

判断タスク（短い出力）の速度・レイテンシの見方

「この内容がルールに適しているか」など出力が短い判断タスク（〜100文字程度）では、 1秒あたりの出力トークン数（スループット）はほぼ無意味です。 出力生成そのものは誤差（約40トークン ÷ 200 tok/s ≒ 0.2秒）で、効くのは「答えが返るまでの総レイテンシ」。 そしてそれは 思考（thinking）するかどうかでほぼ決まります。

  • 目安: 非推論／思考オフ = 0.2〜1秒。思考オン = その5〜30倍（数秒〜数十秒。end-to-end で 10〜150秒に達することも）。
  • 上の表の 列は「思考モードに対応」の意味（厳密な対応可否）。対応していても既定の思考量はモデル次第で、flash-lite / mini / nano は既定が軽く判断タスクでは速い一方、Gemini 3.x や 2.5 Pro 等は既定で思考オンなので要注意。
  • 判断タスクでは reasoning_effort / thinking_level を minimal / none に落とせば、 付きモデルでも速く返ります。
  • キャッシュ: 固定の指示・判定ルールを prompt の先頭（prefix）に置くと、入力が最大90%オフ＆レイテンシも最大85%減（Bedrock の Gemma 4 / Nova、OpenAI・Claude・Gemini・DeepSeek 等でほぼ共通）。「固定 prefix ＋ 小さい可変入力 ＋ 短い出力」の判断タスクに最も効きます。

前提条件・免責（単価・thinking・その他）
  • Thinking: Gemini 公式の「Output (including thinking tokens)」などと同様、本計算でも thinking トークンは出力と同じ $/1Mで積み上げます。内部推論が大きいほど実費は伸びます。
  • 単価の前提: 各公式の Standard。GPT-6 / GPT-5.6 は短コンテキスト帯、Gemini 3.1 Pro 等は「200k トークン以下」、GPT-5.5 / GPT-5.4 系は「272k 未満コンテキスト」、Grok は「200k 未満」（200k 以上は入力・出力とも倍額）の掲載に準拠。コンテキスト量で単価が変わるモデルは、少ない方の帯の1行だけを載せています（Claude Haiku 5.5 は 100k 超で 5倍）。長いプロンプトでは公式どおり単価が変わります。期間限定価格: Gemini 4 Carbon / Argon は 2026-11-30 までのプロモで、12/01 に $4.00/$20.00 へ倍増（Hydrogen は定価）。Gemini 3.6〜3.8 Flash は 2026-12-31 までのプロモで、2027-01-01 に $1.50/$7.50 へ倍増（Flash-Lite 系は対象外で据え置き）。GPT-5.6 Sol は 2026-11-30 までのプロモ（11/21 から延長）。Claude Sonnet 5 の $2/$10 は導入価格から恒久価格に変更（予定されていた 9/1 の値上げは中止）。DeepSeek は「ピーク料金」を掲載し、オフピーク（平日 01:00-04:00 / 06:00-10:00 UTC 以外）は半額。AWS Nova は Amazon Bedrock On-Demand 料金。Gemma 4 は Google 製オープンモデルだが Amazon Bedrock 上でホストされるため AWS Bedrock 枠に分類（推論内蔵。26B-A4B の単価は参考値）。
  • トークナイザの違い（重要）: Claude は 4.7 以降のモデルで新しいトークナイザを使い、同じ文章でも約30%多いトークン数になります（Sonnet 4.6 以前は旧トークナイザ）。したがって単価が下がっても実費が同率で下がるとは限りません。例えば Haiku 4.5（$1/$5、旧）→ Haiku 5.5（$0.10/$0.50、新）は単価では90%減ですが、トークン増加を織り込んだ実ワークロードでの削減幅は約75%とされています。
  • EOL（提供終了）: 各社公式の deprecation / lifecycle 情報に基づく「提供終了（予定）日」。多くは最短日で、事前告知の上で前後し得ます。現行世代など未告知のものは「不明」表記。参考: Gemini 2.5 Pro / 2.5 Flash は 2026-12-01 から 3.8 Flash / 3.5 Flash-Lite へ自動転送（実質の EOL）、gpt-5-mini / gpt-5-nano は 2026-12-11、gpt-4o / gpt-4o-mini / gpt-4.1 / gpt-4.1-mini は 2027-01-14、gpt-5.4-nano は 2027-04-01。EOL 日は「これより早くはない」という意味で延期されることがあります（gpt-4o は当初 2026-10-23 とされていたが 2027-01-14 に、Gemini 2.5 系も 10/16 から延びた）。Nova Premier（2026-09-14）と DeepSeek V4 Flash は EOL 到達済みのため一覧から削除（V4 Flash 宛のリクエストは現在 V4.1-Flash が処理）。
  • 為替レート: ページ読み込み時に Frankfurter API（ECB レート）から自動取得。取得失敗時は ¥150 を使用します。
  • その他: Claude Fast mode やツール課金などは別レートのため、見積もりと実請求がずれることがあります。確定は各プロバイダの usage 表示を参照してください。
  • OpenAI・Anthropic は Cached input 等の別単価があります（本計算では未考慮）。
