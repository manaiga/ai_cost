最終更新日: 2026年10月20日（ OpenAI / Gemini API / ElevenLabs / Deepgram ）

音声の料金はなぜ3つに分けてあるのか（必読）

音声APIは課金単位が3種類混在していて、しかもやりたいことが3つに分かれます。 例えば OpenAI 1社の中だけでも tts-1 は $/100万文字、gpt-transcribe は $/分、gpt-realtime-2.1 は $/100万音声トークンです。

これらを1つの表に並べて「最安比」を出しても意味がないため、 読み上げ / 文字起こし / リアルタイム会話の3タブに分け、 各タブ内で単位を統一しています。タブをまたいだ比較は想定していません （TTSモデルとSTTモデルを比べる人はいないため）。

日本語で使うなら「言語」の設定が結果を大きく変えます。

文字課金のモデルは「1分の音声に必要な文字数」が少ない日本語で有利になり、 音声トークン課金のモデルは言語に関係なく一定です。つまり言語によって有利不利が逆転します。 日本語（約400字/分）と英語（約1,000字/分）で切り替えて確認してください。

前提条件・免責（換算の根拠を含む）
  • 換算に使っている仮定: 音声1分 = 2,400 音声トークン、 音声1分 = {{ charsPerMin.toLocaleString() }} 文字（{{ langs[lang].label }}）、 テキスト {{ langs[lang].charsPerToken }} 文字 = 1 トークン。 音声トークン数は OpenAI 公式が transcribe 系に併記している「$/分」目安と $/1Mトークン 単価から逆算した値です （$0.006/分 ÷ $2.50/1M ≒ 2,400 トークン/分）。コーデックやプロバイダーで前後します。
  • $/音声1分 は比較のための換算値です。公式が定額/分で出しているものはその値をそのまま使い、 文字課金・トークン課金のものは上記の仮定で割り戻しています。実費はプロンプトや発話内容で変動します。
  • 言語で有利不利が逆転します: 文字課金のモデル（OpenAI tts-1、ElevenLabs、Deepgram Aura）は 1分あたりの文字数が少ない日本語で安くなり、音声トークン課金のモデル（Gemini TTS、OpenAI Realtime）は 言語によらず一定です。
  • リアルタイムは入出力比が効きます: 出力（AIの発話）の単価は入力の2倍が一般的なので、 AIがよく喋る設計ほど高くなります。既定は 50:50 です。
  • 期間限定・プロモ: Gemini 3.8 Flash TTS / Flash-Lite TTS は 2026-12-31 までの価格で、 2027-01-01 に倍増します（$9→$18、$6→$12 / 1M音声出力トークン）。 Deepgram の Nova-3 ストリーミングも期間限定価格です。
  • 一次提供元の公式価格のみ掲載しています。AssemblyAI など公式ページで裏取りできなかった プロバイダーは、数値が出典間で食い違うため未収録です。
  • ElevenLabs のサブスク枠は未考慮: 本表は API の従量課金単価です。 月額プランに含まれるクレジット内で収まる場合は実費が下がります。
  • 為替レート: ページ読み込み時に Frankfurter API（ECB レート）から自動取得。取得失敗時は ¥150 を使用します。
