画像生成の料金の読み方（テキストとの違い）

画像生成はテキストと違い 1枚いくら が基本単位です。ただし課金方式は2種類あり、 定額/枚（xAI・Flux・Ideogram 等）と トークン課金（OpenAI・Gemini）が混在します。 本表は後者も $/枚に換算して並べ、そのまま比較できるようにしています。

  • 解像度を必ず見てください。同じモデルでも 1K と 4K で 2〜4倍変わります。 表の「基準解像度」は、その $/枚 が成立する条件です。これを無視した比較は意味を持ちません。
  • 品質設定でも大きく動きます。例えば GPT Image 2.5 は 1024² でも medium $0.013 → high $0.053 → max $0.211 と 16倍の開きがあるため、段階ごとに別行にしています。
  • 編集・img2img は別料金のことがあります。xAI は入力画像1枚につき +$0.01、 Flux.2 Pro の編集は生成より高め（約 $0.045/MP）です。本表はテキストから新規生成の単価です。
  • Batch API を使えば概ね半額になります（Gemini は公式に Batch 価格を掲載）。本表は Standard 価格です。
  • プロンプト側の入力課金は1枚あたり $0.0001 程度で誤差のため、本計算では未考慮です。

前提条件・免責
  • 単価の前提: 各公式の Standard 価格、テキストからの新規生成。Batch を使えば概ね半額です。編集 / img2img は別料金の場合があります（xAI は入力画像1枚につき +$0.01）。
  • $/枚への換算: OpenAI と Gemini はトークン課金のため、公式が示す代表的な1枚あたりの消費量で $/枚 に換算しています。実際のプロンプトや出力内容で前後します。
  • 基準解像度: その単価が成立する解像度です。4K など高解像度では 2〜4倍になります（例: Nano Banana Pro は 1K/2K $0.134 → 4K $0.24）。
  • Imagen 4 は Vertex AI の料金で、Gemini Developer API の価格表には掲載がありません（$0.02 / $0.04 / $0.06 は二次情報に基づく参考値）。
  • 一次提供元のみ掲載: fal / Replicate / Together 等のアグリゲータは同じモデルでもホストごとに価格が異なるため、モデル提供元の公式価格に統一しています。
  • Midjourney は未収録: 従量課金ではなくサブスク（Basic $10/月〜）のため、$/枚の表に混ぜると比較が歪みます。
  • Amazon Nova Canvas は未収録: 2026-09-30 に EOL を迎えるためです。
  • 為替レート: ページ読み込み時に Frankfurter API（ECB レート）から自動取得。取得失敗時は ¥150 を使用します。
  • 料金は変動します。確定は各プロバイダの usage 表示を参照してください。
